# Design note

This file used to be a patent-style invention disclosure (claims, filing
steps, and the old "Compact Kernel" name). That framing is not part of the
project adopters should read.

The technical description of the mechanisms is [SPEC_DRAFT.md](SPEC_DRAFT.md).
How to run the prototype is the repository [README](../README.md) and
[HOWTO.md](HOWTO.md). Limitations are in the README section "Security model
and limitations".

Two-Key is a prototype. It is not a filed patent application, and this
repository is not legal advice.
