# Code of conduct

This project is a technical prototype. Discussion stays on the software.

- Critique the design, the code, and the tests. Do not attack people.
- No exploit details in public issues. Use [SECURITY.md](SECURITY.md).
- Do not commit keys, ledgers, credentials, or someone else's private data.
- Maintainers may close issues and pull requests that are off-topic, that
  demand a production deployment this prototype does not provide, or that
  ignore the fail-closed rules.

Enforcement is a maintainer decision: a warning, a closed thread, or a block.
